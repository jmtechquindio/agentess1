# Módulo 02 — Conversaciones a datos

## Uso

1. Coloca el JSON del ejercicio en esta carpeta con el nombre `dataset.json`.
2. Abre esta carpeta con OpenCode.
3. OpenCode debe detectar el skill `.opencode/skills/conversaciones-a-datos/SKILL.md`.
4. Ejecuta el trabajo sobre el dataset real.
5. No produzcas resultados finales hasta inspeccionar primero la estructura real del JSON.

## Regla principal

No inventar datos. Toda respuesta debe poder rastrearse al `conversation_id` correspondiente.

## Importante

El archivo `dataset.json` es la fuente de datos y debe conservarse sin modificaciones.
