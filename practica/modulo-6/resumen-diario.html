3 señales verificadas
Modelos · Ollama

Beam llega a Ollama Cloud para tareas largas de agentes

Ollama anunció el acceso a Beam, un modelo abierto de Reflection con 501 mil millones de parámetros totales y 23 mil millones activos por token. La oferta gratuita es temporal y se ejecuta en Ollama Cloud; no es una descarga para correrlo localmente. [1]

Para tu equipo: podría servir para probar flujos largos, pero no cumple por sí solo un requisito de inferencia local.

Agentes · infraestructura

Ollama y Fly.io conectan modelos cloud con entornos aislados

La integración permite que agentes dentro de Fly.io Sprites, máquinas Linux aisladas, llamen modelos de Ollama Cloud. Fly.io guarda la clave y cada Sprite necesita permiso explícito para usar el conector. [2]

La idea útil para pymes es el aislamiento de tareas y credenciales. Requiere Fly.io y Ollama Cloud, así que no equivale a un agente local gratuito.

Regulación · Unión Europea

Las reglas de transparencia del AI Act ya entran en aplicación

La Comisión Europea sitúa las reglas de transparencia en agosto de 2026. Entre ellas están informar cuando alguien interactúa directamente con ciertos sistemas de IA e identificar o etiquetar contenido generado, como deepfakes y ciertos textos de interés público. [3]

Si el agente prepara contenido para clientes o publica resúmenes, conviene dejar revisión humana y una forma clara de indicar el uso de IA.

Lectura para tu entregable

Las dos noticias de producto apuntan a servicios cloud y aislamiento, no a conectar automáticamente tu instalación de Hermes con Telegram o Gmail. Para tu demostración, mantén separadas esas integraciones y prueba primero la lectura del correo, sin envío ni borrado.
